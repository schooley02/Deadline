# Game Design — Vision & Core Loop

## Elevator Pitch
Deadline turns your life's to-do lists, habits, and routines into a tower defense game where tasks are zombies you defeat by completing them before they destroy your base.

## Target Audience
Students, young professionals, ADHD individuals, gamers, lifehackers, productivity enthusiasts.

## Primary Goal for the User
Make doing the boring, difficult, repetitive, important stuff in life fun. Beyond points: genuine emotional engagement and behavioral change through self-reflection (run reviews, routine A/B testing, time-of-day pattern insight).

## Aesthetic & Tone
- Visual: pixel art / cartoonish, appropriate for a younger audience.
- Emotional tone: playful & encouraging, strategic. Never punishing or shaming — a lost run is framed as a learning moment ("What adjustments can you make to have a stronger Base in your life?").

## Core Game Loop (typical session)
1. User opens app, sees existing enemies (tasks/habits) approaching the base.
2. User adds a new task → a new enemy appears on the right.
3. User completes a task in real life → taps to defeat the enemy → explosion, points/XP.
4. An enemy reaches the base → base takes damage over time until handled.
5. End of day: base HP replenishes; user reviews and plans tomorrow.

## The Run
A "run" is the streak of days the base survives. Base death ends the run; the user reviews what went wrong (which routines/tasks/habits took the base out) and starts a new run with the same active tasks, habits, and routines. Goal: survive as many days as possible while handling a challenging load.

## Design Principles
1. Game pressure mirrors real-life urgency — enemy speed/menace is a function of real due dates.
2. Reflection over punishment — failure produces data (run history, streak patterns, time-of-day insights).
3. Mechanics must drive real behavior — every reward should map to a genuinely good habit choice; anti-abuse pricing (see ECONOMY.md) keeps tokens from becoming cheat codes.
4. Complexity is unlocked, not front-loaded — new players see the simple loop; routines, heroes, store come with levels.
